---
name: Clear UI text
kind: ui
---

## 01 Labels name what happens
Buttons and menu items start with a verb and name the result. Match the button to the title of the dialog it opens or confirms.
- Before: OK
- After: Delete project

## 02 Errors say what went wrong and how to fix it
No blame, no codes alone, no "something went wrong" without a next step.
- Before: Error 422: invalid input.
- After: That email is already in use. Sign in instead, or use another email.

## 03 Short, then shorter
Cut every word the person doesn't need to act. Most labels fit in three words, most hints in one sentence.
- Before: Please enter your email address in the field below.
- After: Email

## 04 Sentence case
Capitalize only the first word and proper nouns, in buttons, titles and menus.
- Before: Create New Project
- After: Create new project

## 05 Empty states point to the first step
An empty screen says what will appear and how to add the first one.
- Before: No data.
- After: No invoices yet. Create your first invoice to see it here.

## 06 Confirm the result
After an action, say what happened in the past tense, and how to undo it if possible.
- Before: Success!
- After: Project deleted. Undo

## 07 The same word for the same thing
Use one term for each object across the product, matching what the rest of the interface says.
- Before: Remove member / Delete user / Kick from team
- After: Remove member

## 08 No ambiguous pronouns or placeholders
Say which thing. "This", "it" and "item" leave people guessing on a busy screen.
- Before: Are you sure you want to delete this?
- After: Delete "Q3 budget"? This can't be undone.
